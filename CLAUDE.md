# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Overview

This is a documentation and tutorial repository for Claude Code CLI. It contains example-based tutorials demonstrating how to use Claude Code for various development tasks. There is no source code to build or test - the repository serves as an educational resource.

## Working with Examples

The `examples/` directory contains progressive tutorials (01-05) covering:
- Basic CLI usage and file operations
- Code review and improvement suggestions
- Debugging and error fixing
- Test generation for multiple frameworks
- Code refactoring and security improvements

When modifying examples, maintain the progressive learning approach and use practical, real-world scenarios.

## Important Context

This repository demonstrates Claude Code capabilities across multiple languages (JavaScript, Python, TypeScript) but does not itself contain executable code. Examples show how to:
- Generate tests for Jest, pytest, unittest, Mocha, Vitest, and JUnit
- Debug various types of errors (syntax, runtime, logic, async)
- Refactor code for security and best practices
- Review code for improvements

When creating new examples or modifying existing ones, follow the established pattern of showing both the problematic code and the Claude Code commands to fix it.
